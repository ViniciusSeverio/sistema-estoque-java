# 📦 Sistema de Estoque em Java

Sistema de gerenciamento de estoque desenvolvido em **Java** como projeto prático de estudos em desenvolvimento Backend.

## 🚀 Funcionalidades

* Cadastro de produtos
* Listagem de produtos
* Busca de produtos por código
* Entrada de estoque
* Saída de estoque
* Validação de dados
* Cálculo do valor total em estoque

## ▶️ Como executar

1. Clone este repositório.
2. Abra o projeto em uma IDE Java, como Eclipse.
3. Execute a classe `Main`.
4. Utilize o menu apresentado no console.

## 🎯 Objetivo

Projeto desenvolvido para consolidar conhecimentos fundamentais de **Java** e praticar a construção de uma aplicação de gerenciamento de estoque.

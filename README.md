# 📦 Sistema de Estoque em Java

Sistema de gerenciamento de estoque desenvolvido em **Java** como projeto prático de estudos em desenvolvimento Backend e Programação Orientada a Objetos (POO).

## 🚀 Funcionalidades

* Cadastro de produtos
* Listagem de produtos
* Validação dos dados dos produtos
* Validação de código duplicado
* Entrada de estoque
* Saída de estoque
* Validação de quantidade
* Validação de estoque insuficiente
* Cálculo do valor total em estoque
* Busca de produtos por código para movimentação

## ▶️ Como executar

1. Clone este repositório.
2. Abra o projeto em uma IDE Java, como Eclipse.
3. Execute a classe `Main`.
4. Utilize o menu apresentado no console.

## 🎯 Objetivo

Projeto desenvolvido para consolidar conhecimentos fundamentais de **Java e POO**, praticando a construção de uma aplicação de gerenciamento de estoque com regras de negócio e controle de movimentações.
